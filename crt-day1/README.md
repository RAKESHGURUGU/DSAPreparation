# CRT Training – Day 1

## Introduction
Today was the first day of our Campus Recruitment Training (CRT) classes. In this session, I learned the fundamentals of Java programming and practiced writing basic Java programs.

## Topics Covered

### 1. Java Basics
- Introduction to Java.
- Basic structure of a Java program.
- Understanding the `main()` method.
- Java syntax and rules.

### 2. Simple Java Programs
- Writing and executing basic Java programs.
- Understanding variables and data types.
- Performing basic operations.

### 3. Java Operators
- Arithmetic operators (`+`, `-`, `*`, `/`, `%`).
- Relational operators (`>`, `<`, `>=`, `<=`, `==`, `!=`).
- Logical operators (`&&`, `||`, `!`).
- Assignment operators (`=`, `+=`, `-=`, etc.).

### 4. Input and Output Statements
- Taking input using the `Scanner` class.
- Using `System.out.print()`.
- Using `System.out.println()`.
- Reading different data types from the user.

### 5. Conditional Statements
- `if` statement.
- `if-else` statement.
- `else-if` ladder.
- Nested `if` statements.
- `switch` statement.

## What I Learned
- Basic understanding of Java programming.
- How to write and execute simple Java programs.
- How to use operators in Java.
- How to accept input and display output.
- How to make decisions using conditional statements.

## Conclusion
The first day of CRT training helped me understand the fundamentals of Java programming. I practiced basic programs and learned how to use operators, input/output statements, and conditional statements. These concepts will help me improve my programming skills and prepare for upcoming coding assessments and placement opportunities.
